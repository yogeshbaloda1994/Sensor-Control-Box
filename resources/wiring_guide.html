Integrated Wiring Guide: Arduino Uno R4 WiFi

This document details the remapped connections to accommodate the RS485 Shield and CD22 Laser Sensor while avoiding pin conflicts.

Hardware Notes:
  • Power: CD22 is powered by 12V from the Vin pin (supplied by DC Barrel Jack).
  • Serial Configuration: Set the RS485 Shield SW1 to "HW". This connects the shield to Pins 0 (RX) and 1 (TX), addressed as Serial1 on the Uno R4 WiFi.
  • Pull-ups: Don't forget the 2.2kΩ resistors on D2 and D3 for the optical encoder.

Optimized JST-XH Connector Layout

Connectors should be mounted in the Prototyping Area (Centered Group) with JST-XH tabs facing the Left Edge.

Component Connector Grid Pos (Col, Row) Pin Mapping (Pin 1 to N)
CD22 Power 2-Pin C7-C8, R1 1: Vin (12V), 2: GND
Joy Power 2-Pin C9-C10, R1 1: 5V, 2: GND
LCD (I2C) 4-Pin C1-C4, R2 1: GND, 2: 5V, 3: SDA (A4), 4: SCL (A5)
Joy Controls 5-Pin C1-C5, R4 1: A0 (X), 2: A1 (Y), 3: D2 (EncA), 4: D3 (EncB), 5: D4 (Btn)
W48M Switch 4-Pin C6-C9, R7 1: GND, 2: 5V, 3: D5 (Signal), 4: D6 (LED+)
Soldering Strategy:
  • Vertical Power Rails: Run a bare wire down Column 8 for GND and Column 10 for 5V. Tap all connectors into these rails.
  • Joystick Pull-ups: Mount 2.2kΩ resistors directly between the Joy Control pins (3 & 4) and the 5V rail.
  • Cable Exit: Bundle all JST cables to exit via the left side, keeping the RS485/DB9 ports clear.

Integrated Test Code


#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Remapped Pins
const int pinJoyX = A0;
const int pinJoyY = A1;
const int pinJoyEnA = 2; 
const int pinJoyEnB = 3; 
const int pinJoySW = 4;  
const int pinExtSW = 5;
const int pinExtLED = 6;

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  Serial.begin(9600);      // USB Serial for Debugging
  Serial1.begin(9600);     // Hardware Serial for CD22 (RS485 Shield SW1 set to "HW")
  
  pinMode(pinJoySW, INPUT_PULLUP);
  pinMode(pinExtSW, INPUT_PULLUP);
  pinMode(pinExtLED, OUTPUT);
  
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("System Ready");
}

void loop() {
  // Read Joystick and Switch
  int xVal = analogRead(pinJoyX);
  bool joyBtn = !digitalRead(pinJoySW);
  bool extBtn = !digitalRead(pinExtSW);

  // Control External LED
  digitalWrite(pinExtLED, extBtn ? HIGH : LOW);

  // CD22 Serial Pass-through (Debug)
  if (Serial1.available()) {
    char c = Serial1.read();
    Serial.write(c); // Echo to USB
  }

  // Update LCD
  lcd.setCursor(0, 0);
  lcd.print("X:"); lcd.print(xVal);
  lcd.print(" J:"); lcd.print(joyBtn ? "V" : "X");
  
  lcd.setCursor(0, 1);
  lcd.print("Ext SW: "); lcd.print(extBtn ? "ON " : "OFF");
  
  delay(10); // Faster loop for Serial processing
}
